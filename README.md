# Big-Data-Project
 An academic project carried out by a team. Application of Big Data techniques to the analysis of open-source public security data, investigating the distribution and incidence of intentional lethal violent deaths, robberies, and thefts.

-------------

## For this project, official data from the Secretariat of Public Security and Social Defense (SSPDS)—consolidated up to November 2025, the period corresponding to the project's presentation—were used. Data manipulation and processing were performed using NumPy and Pandas, while the creation of graphical visualizations was handled by Seaborn and Matplotlib, facilitating the identification of patterns and trends, as well as exploratory analysis.
